Design notes, not page text. The message page (/inbox/<id>, TD-129): one mail entry whole, reached from the row's text, from Enter on the ringed row, and from a trail row's re. The head is the row's head; the text is whole, with details open (TD-127's shape, when it lands); then its thread — the question it answers or the replies it drew, the outcome under the question it closes, the system notes about it — oldest first, each in its kind's row shape, none of it a control built from text; then the row's own controls again at the foot, the same RPCs, so the entry is answered here and the page returns to the list when the answer removes the row. Back (and Esc) returns to the list at the same row, ringed, with the filters as they were; j / k walk the filtered list without going back. A state row and a board row have no page: Open and Open board stay theirs. Reading marks nothing. No preview pane: at any width the entry opens as this page.
