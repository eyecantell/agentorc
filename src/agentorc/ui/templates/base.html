Add an entry to the ledger

Write what you have: a title, or a page. The number, the header lines and the file locations are found for you, and you are asked only what cannot be found.

Type
drafts the entry and lands it by PR. Its questions come to your Inbox; the entry's id and PR come back as the outcome.
Keys
Single keys, live while nothing you type into has focus — a composer, the filter, a reply box, the terminal. Each presses a button the page already draws, and does nothing where that button is absent.
The ring is the keyboard's focus ring — Tab reaches the same places. It is nowhere until a key moves it.
